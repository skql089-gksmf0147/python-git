
무비킹 주인이 사이트를 청소하면서 영상 카드의 이름(target_class)을 

원래 쓰던 video-card에서 movie-box 같은 걸로 바꿨다고 가정해 볼게요. 

그러면 우리 프로그램에 영상이 안 뜨기 시작할 겁니다. 이때 이렇게 하시면 됩니다.

1단계: 내 깃허브 저장소로 가기인터넷 브라우저를 켜고 본인의 깃허브 주소로 들어갑니다.

https://github.com/skql089-gksmf0147/media-config

2단계: 파일 수정 버튼 누르기화면에 보이는 config.json 파일을 마우스로 클릭합니다.
파일 내용이 나오는 화면 우측 상단을 보면 연필 모양의 아이콘 ✏️ (Edit this file) 버튼이 있습니다. 
그걸 클릭합니다.

3단계: 내용 글자만 바꾸기메모장처럼 글자를 고칠 수 있게 바뀌면,바뀐 사이트 규칙에 맞게 단어만 슥슥 고쳐줍니다.

JSON{
    "target_class": "movie-box",
    "title_selector": ".video-title a",
    "wait_time": 5
}

만약 사이트가 너무 느려져서 로딩 시간을 늘려야 한다면 wait_time을 5에서 8이나 10으로 늘려주셔도 됩니다!

4단계: 저장(Commit)하기수정을 완료했다면 우측 상단의 초록색 Commit changes... 버튼을 누릅니다.
팝업창이 뜨면 한 번 더 초록색 Commit changes 버튼을 누릅니다.

😎 끝입니다! 파이썬 프로그램 확인하기깃허브에서 저장을 마쳤다면 
컴퓨터에 켜져 있는 내 프로그램을 껐다 켜거나 데이터 갱신 버튼을 눌러보세요.
프로그램이 켜지면서 자동으로 내 깃허브 방에 접속해 
"아, 주인이 규칙을 movie-box로 바꿔놨구나!" 하고 최신 규칙을 알아서 다운로드받아 올 겁니다.  
그리고 언제 그랬냐는 듯이 다시 영상을 정상적으로 쏙쏙 긁어오게 됩니다.
이제 이 파이썬 프로그램을 exe 파일로 만들어서 TV용 컴퓨터에 넣어두거나 다른 사람에게 선물하더라도, 
사이트가 바뀔 때마다 컴퓨터를 켜서 소스코드를 수정할 필요가 없어진 거예요. 

스마트폰 게임들처럼 원격으로 조종하는 멋진 시스템을 완벽하게 마스터하신 걸 축하합니다! 고생 많으셨어요!
